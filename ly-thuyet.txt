STRING(Hiểu sâu)
Các method quan trọng phải nhớ:
1. slice()
dùng để cắt chuỗi.
VD: let str = "hello"
 consolo.log(str.slice(1, 4); // Nó sẽ hiển thị chuỗi từ 1-4 => "ell"
Có thể hiểu như là sẽ đếm dữ liệu trong string từ 0-5 rồi chọn vùng muốn cắt và in ra.

2. substring()
Cũng dùng gần giống với slice() nhưng sẽ chỉ lấy tới 0 -> khoảng trước của 4 chứ không lấy 4.

3. trim()
Xóa khoảng trắng của chuỗi.
VD: "   hello   ".trim(); // thì khi này trim() sẽ xóa khoảng trắng dư thừa đi và trả lại kết quả là "hello".

4. includes()
kiểm tra có chứa không.
VD: "hello".includes("he"); // Kết quả hiển thị sẽ là true / false. Trong ví dụ thì sẽ hiển thị kết quả là true. Tuy nhiên, cần lưu ý: includes() có phân biệt chữ hoa và chữ thường nên nếu không nhập đúng như string khai báo mà kiểm tra thì kết quả vẫn sẽ trả về false.

5. indexOf()
Dùng để tìm vị trí.
VD: "hello".replace("l"); // Kết quả trả về sẽ là "2". Vì nó sẽ đếm vị trí trong string đã khai báo, và nếu 2 ký tự giống nhau đứng trong cùng chuỗi thì sẽ hiển thị vị trí đầu tiên của ký tự đó.

6. replace()
Dùng để thay thế nội dung trong chuỗi string.
VD: "hello",replace("h", "H"); // kết quả trả về sẽ là "Hello". Khi muốn thay đổi nội dung trong string thì cần đưa ra đoạn cần thay đổi và nôi dung muốn thay đổi cách nhau một dấy ",".

7. split() (cực quan trọng)
Dùng để biến chuỗi string thành mảng array.
VD: "a, b, c".split(","); //['a', 'b', 'c']

8. toUpperCase()/toLowerCase()
toUpperCase dùng để chuyển chuỗi thành chứ in hoa
toLowerCase dùng để chuổi chuỗi về chữ thường 
VD: 
"hello".toUpperCase(); // "HELLO"
"HELLO".toLowerCase(); // "hello"

9. localeCompare()
- Dùng để so sánh chuỗi string 
- Cú pháp: a.localeCompare(b)
* QUY TẮC: 
+ Nếu < 0 thì a đứng trước b
+ Nếu > 0 thì b đứng trước a
+ Nếu = 0 thì giống nhau

(+) Dùng trong sort():
arr.sort((a, b) => a.name.localeCompare(b.name));
=> Sắp xếp từ A -> Z

arr.sort((a, b) => b.name.localeCompare(a.name));
=> Đảo ngược lại xếp từ Z -> A

ARRAY (Trọng tâm: map, filter, find)

1. map() - Biến đổi dữ liệu
Cách dùng: arr.map(item => ...)
VD: 
let arr = [1, 2, 3];
let result = arr.map(x => x *2);
console.log(result);
// [2, 4, 6]

(=) map = giữ nguyên số lượng phần tử

2. filter() - Lọc dữ liệu
Cách dùng: arr.filter(item => điều kiện)
VD: 
let arr[1, 2, 3, 4];
let result = arr.filter(x => x % 2 === 0);
console.log(result);
// [2, 4]

(=) filter = trả về ít hơn hoặc bằng số lượng phần tử.

3. find() - tìm 1 phần tử 
Cách dùng: arr.find(item => điều kiện)
VD: 
let arr = [1, 2, 3, 4];
let result = arr.find (x => x > 2);
console.log(result);
// 3

(=)find = chỉ trả về 1 phần tử đầu tiên.

4. reduce()
ruduce dùng để gom nhiều giá trị thành 1 giá trị
Cách dùng: 
arr.reduce((acc, item) => {return acc + item;}, 0)
Giải thích:
acc -> biến tích lũy (tổng)
item -> phần tử hiện tại
0 -> giá trị ban đầu

5. splice()
splice() dùng để: thêm/xóa/thay thế phần tử trong mảng. Và nó thay đổi trực tiếp mảng gốc
Cú pháp: arr.splice(vị trí, số lượng xóa, phần tử mới)

6. sort() 
- Dùng để sắp xếp phần tử trong mảng.
- Cú pháp: arr.sort((a, b) => { // return gì đó });
- Quy tắc: 
 + return < 0 -> a đứng trước b
 + return > 0 -> b đứng trước a
 + return = 0 -> giữ nguyên
 * Trong đó a và b là 2 phần tử bất kỳ trong mảng đang được đêm ra so sánh
- Sắp xếp giảm dần: arr.sort((a, b) => a - b)
 + a < b -> a âm -> a lên trước
 + a > b -> a dương -> b lên trước
- Sắp xếp tăng dần: arr.sort((a, b) => b - a)

LOCAL STORAGE LÀ GÌ?
- localStorage là bộ nhớ trình duyệt
- Nó dùng để: 
 + Lưu dữ liệu
 + Giữ lại khe reload
 + Không mất khi tắt tab
VD: 
localStorage.setItem("name", "Toan");
=> Lưu vào brower.
localStorage.getItem("name");
=> Lấy ra: // "Toan"
(+) LƯU Ý QUAN TRỌNG: localStorage chỉ lưu được STRING

JSON.stringify() & JSON.parse()

+) stringify():
JSON>stringify(todos);
-> biến: ["a", "b"]
-> Thành: `["a", "b"]`

+) parse()
JSON.parse(data);
-> Biến ngược lại: `["a", "b"]`
-> Thành ["a", "b"]

Flow chuẩn của app (đây là cái quan trọng nhất):
Load -> lấy data -> render -> User action -> update -> save -> render

LỌC KÝ TỰ LÀ GÌ? 
- Lọc ký tự là giữ lại những ký tự hợp lệ, xóa những ký tự không hợp lệ.
- Ví dụ: 
  + input: "12a3b.4-5"
  + output: "123.45"
- Cách hoạt động cốt lõi là: 
 + Luôn thoe flow: User nhập -> lấy value -> xử lý -> gán lại value

Code pattern: 
input.addEventListener("input", function(){
    let value = input.value;

    // xử lý value

    input.value = value;
});

- Công cụ chính: regex
 + Cú pháp: /string/
 + Ví dụ: /[^0-9]/g
  	-> Nghĩa là: ^ là phủ định (not), 0-9 là số
	=> Tất cả ký tự không phải số.
- Hàm quan trọng replace()
 + Cú pháp: string.replace(regex,"");
 + Ví dụ: "123abc".replace(/[^0.9]/g, ""); // "123"
- Các kiểu phổ biến:
 + Chỉ cho số: value = value.replace(/[^0.9]/g, "");
 + chỉ cho số + dấu chấm: value = value.replace(/[^0-9.]/g, "");
 + Chỉ cho số + âm + thập phân: value = value.replace(/[^0-9.-]/g, "");
